# Quick Start Guide - Launcher Website

Get the website running in 2 minutes.

## Option 1: Super Quick (npm)

```bash
cd web
npm install
npm run dev
```

Visit: http://localhost:3000

## Option 2: With pnpm (Faster)

```bash
cd web
pnpm install
pnpm dev
```

Visit: http://localhost:3000

## Option 3: With yarn

```bash
cd web
yarn install
yarn dev
```

Visit: http://localhost:3000

## Option 4: With bun (Fastest)

```bash
cd web
bun install
bun run dev
```

Visit: http://localhost:3000

---

## What You'll See

1. **Home Page** - Hero section with features and CTA buttons
2. **Features Page** - Detailed feature showcase
3. **Download Page** - Platform downloads and installation guide
4. **Docs Page** - Expandable documentation sections
5. **Support Page** - Contact form and FAQs

## All Buttons Work!

- Navigation links
- Download buttons
- Contact form
- Newsletter subscription
- Mobile hamburger menu

## Make Changes

Files are in the `app/` directory. Hot reload is enabled - just save and see changes instantly!

## Stop the Server

Press `Ctrl+C` in your terminal

## Build for Production

```bash
npm run build
npm start
```

---

That's it! You're running the Launcher website. 🚀
